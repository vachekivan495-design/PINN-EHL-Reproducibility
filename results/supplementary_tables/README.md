# Machine-readable supplementary tables

These CSV files provide the unrounded machine-readable values corresponding
to Supplementary Tables S1--S4 of the associated manuscript.

- `Supplementary_Data_S1_case_level_global_errors.csv`: 48 condition-level
  global and scalar-error records for the 0.1%, 1%, and 100% models.
- `Supplementary_Data_S2_high_pressure_zone_errors.csv`: 48 condition-level
  high-pressure-zone error records.
- `Supplementary_Data_S3_extrapolation_conditions.csv`: definitions of the
  eight controlled one-parameter extrapolation conditions.
- `Supplementary_Data_S4_repeated_seed_results.csv`: individual test-set mean
  errors from the three 1%-supervision random seeds.

All error columns ending in `_percent` are expressed in percentage units.
S1, S2, and S4 were exported from the formal evaluation JSON files; S3 was
exported from the frozen condition design used in the manuscript.
